SMART HIVES WEBSITE
===================
Open index.html in any browser. No install needed.

Files: index.html, about.html, products.html, honey.html, contact.html, style.css, script.js, assets/

BEFORE GOING LIVE
1. Open script.js and fill in SMART_HIVES_CONFIG (email and/or WhatsApp number)
   so the enquiry form sends to you. Until then it shows the finished message to copy.
2. Add real prices if you want them (search "Price on request" in products.html).
3. Add team, contact details and verified results when you have them.

Free hosting: drag this whole folder onto Netlify Drop, or use GitHub Pages / Cloudflare Pages.

HERO VIDEO
Put your bee video in assets/video/ named bees.mp4 (and optionally bees.webm).
Keep it short (10-20 s), no sound needed, under ~8 MB. Until then the hero shows the apiary photo.
